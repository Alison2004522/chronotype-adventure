## 🧭 一、 遊戲簡介與教育理念

**《生理時鐘大冒險》（Chronotype Adventure）** 是一款根據閱讀文本《晨型人 vs. 夜型人》精心設計的 2D 網頁互動教育遊戲。

### 🌟 核心理念與文章重點
每個人的作息偏好與體內生理時鐘密切相關，在科學上稱為「時型」（Chronotype）：
1. **晨型人**：通常較早起床，在早晨能迅速保持清醒與專注。
2. **夜型人**：通常偏好晚睡晚起，在午後或夜晚精神狀態較佳。
3. **無絕對優劣**：晨型人與夜型人是天生生理時鐘的差異，夜型絕不代表懶惰或不認真。
4. **充足睡眠最重要**：晚睡絕不代表可以犧牲睡眠時數；國小高年級至國中一年級（10～13 歲）學生每日建議需要 **9～12 小時** 的充足睡眠。
5. **固定上學作息調適**：面對現代社會固定 08:00 上學時間，夜型學生可透過「減少睡前使用手機避免藍光刺激」、「降低睡前燈光照度營造放鬆氛圍」、「安排安靜放鬆閱讀」等睡前環境優化，逐步找到適合自己的健康生活節奏。

> **核心教育理念**：每個人的生理時鐘可能不同，沒有哪一種時型一定比較優秀。重要的是找到能兼顧個人需求、學習與健康的生活方式！

## 🕹️ 二、 三大冒險關卡設計

玩家扮演「生理時鐘管理師」，協助三位好友找到最佳生活節奏：

| 關卡 | 關卡名稱 | 登場角色 | 作息情境 | 關卡任務與規格 |
|:---:|:---|:---|:---|:---|
| **第 1 關** | **晨光活力計畫** | **Inu**（晨型小狗） | 早起晨型人的一天 | 將 6 張活動卡片（起床、吃早餐、上學、運動、讀書、睡覺）安排到 6 個時間格（07:00、07:30、08:00、16:00、19:00、21:30）中。 |
| **第 2 關** | **夜貓子的時間表** | **Neko**（夜型小猫） | 週末假日自由作息 | 將 6 張活動卡片（起床、吃早餐、閱讀、運動、自由活動、睡覺）安排到 6 個時間格（09:00、10:00、14:00、17:00、20:00、23:00）中，探索夜型人傍晚與夜晚的高效專注。 |
| **第 3 關** | **健康作息大挑戰** | **Neko**（12 歲）<br>＋ **Usagi**（小幫手） | 面對固定上學（08:00）的作息調適 | **雙重任務**：<br>① **任務一 睡前環境整理**：點擊手機（收起手機）、檯燈（柔和燈光）、書本（安靜閱讀）切換放鬆狀態。<br>② **任務二 睡眠時間安排**：選擇 20:30～23:00 就寢時間，固定 07:00 起床，即時計算睡眠時數（符合 9～12 小時建議）。 |

## 🎯 三、 最核心遊戲規則：自由過關機制

**本遊戲不需要達到 100 分，也不需要達到任何指定分數，才可以進入下一關。**

- 只要完成該關的基本操作任務，即可點擊查看結果，並**無條件解鎖進入下一關**！
- 分數（0～100 分）僅作為學習回饋，協助玩家觀察不同時間安排的優缺點，絕不可作為過關限制。
- 無論玩家得到 0 分、30 分、50 分、75 分或 100 分，均能自由前進並在第三關後領取「生理時鐘管理大師」通關徽章！
- 遊戲結果畫面明確提示：「分數是遊戲中的參考回饋，不代表你的能力或健康程度。」

## 🎮 四、 雙軌操作與特色功能

1. **滑鼠拖曳與平板觸控（雙模式）**：
   - 支援原生 HTML5 Drag & Drop，拖曳卡片靠近目標時間槽位時自動吸附定位。
   - 支援點擊選取模式（點擊卡片發光選取 ➔ 點擊時間格放置），手機與平板操作極其順暢！
2. **即時精神能量值（0～100%）**：
   - 隨時間表安排進度平滑模擬精神能量條，直觀呈現作息調整效果（遊戲示意，非醫學測量）。
3. **臥室互動調整場景（第 3 關）**：
   - 手機、檯燈、書本三大生活物件，點擊即時切換健康狀態，並顯示科學助眠原理提示。
4. **內建 Web Audio API 音效合成引擎**：
   - 包含點擊音（Pop）、吸附音（Snap）、檢查音（Check）、成功音（Success）與歡慶大合音（Fanfare），支援右上角 🔊／🔇 靜音開關。
5. **多專案並存無覆蓋**：
   - 本儲存庫同時保留《名畫變裝大師》（`/masterpiece-makeover/`）與《生日蛋糕小店長》（`/birthday-cake-manager/`），所有專案互不干擾、各自獨立完整運作。

## 🚀 六、 本地測試與 GitHub Pages 部署指南

### 本地測試
本專案為純靜態網頁架構，不需安裝 npm 套件或啟動後端伺服器：
1. **直接開啟**：用任何現代瀏覽器（Google Chrome、Microsoft Edge、Safari 等）直接連點開啟 `index.html`。
2. **本機伺服器（推薦）**：
   ```bash
   # 使用 Python
   python -m http.server 8080
   # 或使用 npx
   npx serve .
   ```
   瀏覽器開啟 `http://localhost:8080` 即可遊玩。

### 自動化驗證測試
執行指令：
```bash
node tests/verify.js
```
自動檢驗所有素材完整性、DOM ID 匹配性、關卡設定以及台灣繁體中文排版規範。
