## 🧭 一、 遊戲簡介與教育理念

**《生理時鐘大冒險》（Chronotype Adventure）** 是一款根據閱讀文本《晨型人 vs. 夜型人》設計的 2D 網頁互動教育遊戲。

### 🌟 核心理念與文章重點
每個人的作息偏好與生理時鐘密切相關，在科學上稱為「時型」（Chronotype）：
1. **晨型人**：通常較早起床，在早晨能迅速保持清醒與專注。
2. **夜型人**：通常偏好晚睡晚起，在午後或夜晚精神狀態較佳。
3. **無絕對優劣**：晨型人與夜型人是天生生理時鐘的差異，夜型不代表懶惰或不認真。
4. **充足睡眠最優先**：晚睡絕不代表可以犧牲睡眠時數；國小高年級至國中一年級（10～13 歲）學生每日需要 **9～12 小時** 的充足睡眠。
5. **適應固定作息**：面對現代社會與學校早上 08:00 的固定上學時間，夜型學生可透過「降低睡前燈光照度」、「睡前 1 小時停止使用手機避免藍光干擾」、「收拾書包放鬆心情」等睡前環境優化，逐步找到適合自己的健康節奏。

> **核心教育理念**：不是每個人都適合同一套時間表，重要的是認識自己的生理時鐘，兼顧生活需求與健康！

## 🕹️ 二、 三大冒險關卡設計

玩家扮演「生理時鐘管理師」，協助三位好友找到最佳生活節奏：

| 關卡 | 關卡名稱 | 登場角色 | 作息情境 | 任務重點與教育意涵 |
|:---:|:---|:---|:---|:---|
| **第 1 關** | **晨光活力計畫** | **Inu**（晨型人） | 上學日作息安排 | 晨型人容易早起，但**早起的前提是提早就寢**！若早起（06:30）卻熬夜，依然會造成睡眠不足。安排 21:00～06:30（9.5 小時）健康睡眠。 |
| **第 2 關** | **夜貓子的時間表** | **Neko**（夜型人） | 週末假日自由作息 | 不受固定上學限制時，夜型人可安排較晚起床（08:30）與就寢（23:00），並將高效自學排在精神最佳的夜晚（19:30～21:30），睡足 9.5 小時。 |
| **第 3 關** | **健康作息大挑戰** | **Neko**（12 歲）<br>＋ **Usagi**（引導夥伴） | 面對固定上學（08:00）的作息調適 | **雙重任務**：<br>① **任務 A 睡前環境優化**：點擊調整手機、檯燈、窗簾、書桌、鬧鐘與床鋪（至少達成 2 項）。<br>② **任務 B 時間表排程**：在學校固定時間（08:00～16:00）限制下，排入 21:30～07:00（9.5 小時）充足好眠與放鬆活動。 |

## 🎯 三、 評分規準與回饋機制

每關完成作息安排後，點擊「📋 檢查我的時間表！」，系統會依據 4 項透明標準嚴謹評分（滿分 100 分），並由夥伴 Usagi 提供具體改善建議：

| 評分項目 | 滿分 | 評量依據 |
|---|:---:|---|
| **💤 睡眠安排** | **40 分** | 依實際排入睡眠時數計算：符合 10～13 歲建議時數（9～11.5 小時）得滿分 40 分；8～8.9 小時得 28 分；7～7.9 小時得 15 分；<7 小時得 5 分；未排睡眠 0 分。 |
| **⏰ 時間規劃合理性** | **30 分** | 起床、用餐與日間活動的邏輯順序（起床在早餐前、早餐在上學前）、無活動時間衝突、無遺漏重要時段。 |
| **🎯 符合作息需求** | **20 分** | 是否符合角色的時型偏好（晨型人善用早晨時段；夜型人善用夜晚專注；上學日提早放鬆沉澱）。 |
| **🌱 健康生活習慣** | **10 分** | 是否安排運動與休閒放鬆；在第三關中是否完成至少 2 項睡前臥室環境健康優化。 |
| **總分** | **100 分** | 滿分 100 分，絕不以隨機給分，完全依據時間資料模型精算。 |

### 🏆 評價等級
- **90～100 分**：👑「生理時鐘管理大師！」
- **70～89 分**：🌟「作息安排高手！」
- **50～69 分**：🌱「很棒的時間規劃員！」
- **0～49 分**：💡「再調整一下，時間表會更理想！」

## 🎮 四、 雙軌操作與特色功能

1. **滑鼠拖曳與平板觸控**：
   - 支援 HTML5 Drag & Drop，拖曳活動卡片靠近時段槽位時自動吸附定位。
2. **點擊放置替代操作（點擊卡片 ➔ 點擊時間格）**：
   - 避免手機或平板螢幕拖曳不順暢，點擊托盤卡片後，目標空槽位會發光提示，點擊槽位即可一鍵放入！
3. **即時精神能量值（0～100%）**：
   - 即時模擬能量條，搭配生動表情（😆 活力充沛／😊 精神良好／😐 普通／🥱 疲累／😵 疲憊），直觀呈現作息調整效果。
4. **互動式臥室調整場景（第 3 關）**：
   - 手機、檯燈、書桌、窗簾、鬧鐘、床鋪 6 大生活物件，點擊即時切換健康狀態，並顯示科學助眠原理解說。
5. **內建 Web Audio API 音效合成引擎**：
   - 包含點擊音（Pop）、吸附音（Snap）、成功音（Success）、計分音（Score）與通關歡慶大合音（Fanfare），支援右上角 🔊／🔇 靜音切換。

## 🚀 六、 本地測試與 GitHub Pages 部署指南

### 本地測試
本專案為純靜態網頁架構，不需安裝 npm 套件或啟動後端伺服器：
1. **直接開啟**：用任何現代瀏覽器（Google Chrome、Microsoft Edge、Safari 等）直接雙擊開啟 `index.html`。
2. **本機伺服器（推薦）**：
   ```bash
   npx serve .
   # 或使用 Python
   python -m http.server 8080
   ```
   開啟瀏覽器瀏覽 `http://localhost:8080` 即可遊玩。

### 自動化驗證測試
本專案附帶完整驗證測試腳本，執行指令：
```bash
node tests/verify.js
```
自動檢驗所有素材完整性、DOM ID 匹配性、關卡設定以及台灣繁體中文規範。

### GitHub Pages 部署步驟
1. 將本專案推送至 GitHub 儲存庫的 `main` 分支。
2. 進入儲存庫的 **Settings** ➔ **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 選擇 **Deploy from a branch**。
4. **Branch** 選擇 `main` 分支與 `/(root)` 目錄，點擊 **Save**。
5. 數分鐘後即可透過專屬網址直接在瀏覽器遊玩！
