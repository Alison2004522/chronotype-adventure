## 🎨 一、 遊戲簡介與教育理念

**《名畫變裝大師》（Masterpiece Makeover）** 是一款根據閱讀文本《模仿世界名畫》設計的 2D 網頁互動教育遊戲。

### 🌟 核心背景
在 2020 年新冠疫情居家期間，世界各地掀起了一股「在家模仿世界名畫」的風潮。人們利用身邊唾手可得的毛巾、帽子、圍裙、玩偶、杯子等日常用品，重新演繹世界名畫人物的姿勢、物品與構圖，並拍照分享至社群平台。

本遊戲將這份富含幽默感與創造力的真實生活經驗轉化為課堂互動遊戲，讓學生化身為「名畫變裝工作室」的藝術助理，引導學生：
1. **細膩觀察**：觀察名畫人物的服裝色彩、頭飾形狀、臉部朝向與眼神光采。
2. **靈活替代**：體會如何以生活中常見的普通物件替代名畫中的特定道具。
3. **空間構圖**：理解物件的前後層次、桌子與主體距離、人物大小比例與背景光影對相似度的影響。
4. **激發創意**：在有限資源中發揮巧思，體會「藝術源於生活，不需昂貴道具也能創造驚喜」的核心理念。

## 🕹️ 二、 遊戲關卡設計

遊戲依序挑戰三幅不同繪畫風格、構圖難度與時代背景的世界名畫：

| 關卡 | 關卡名稱 | 模仿名畫 | 藝術家與年份 | 核心生活道具 | 構圖與姿勢特徵 |
|:---:|:---|:---|:---|:---|:---|
| **第 1 關** | **神祕的珍珠少女** | 《戴珍珠耳環的少女》 | 維梅爾（約 1665 年） | 藍色毛巾、黃色布料、珍珠造型耳環 | 微微側身回眸、專注凝視、極簡深色背景 |
| **第 2 關** | **牛奶魔法師** | 《倒牛奶的女僕》 | 維梅爾（約 1660 年） | 白色頭巾、藍色圍裙、水壺、麵包 | 站立雙手倒水、前景木桌與麵包、中間偏右構圖 |
| **第 3 關** | **畫家的神祕帽子** | 《戴灰氈帽的自畫像》 | 梵谷（1887 年） | 灰色帽子、藍色外套、白色圍巾 | 半身肖像微側、深邃眼神、梵谷旋渦筆觸背景 |

## 🎯 三、 評分規準與回饋機制

每關完成模仿後，系統依照 4 項具體規準進行透明評分（滿分 100 分），並給予一至兩句具體且鼓勵性的改進建議：

| 評分項目 | 滿分 | 評量依據 |
|---|:---:|---|
| **🧺 道具搭配** | **40 分** | 是否選對名畫核心特徵之關鍵道具（若選到干擾道具如現代墨鏡、足球則適度扣分）。 |
| **🧍 姿勢模仿** | **30 分** | 人物身體面向角度、雙手動作與眼神表情是否契合原作特徵。 |
| **📐 構圖還原** | **20 分** | 人物左右橫向位置（X 軸）、鏡頭縮放比例（Scale）與背景氛圍是否到位。 |
| **💡 創意運用** | **10 分** | 巧妙運用生活替代品、額外搭配加分道具（如棕色大衣、調色盤）之綜合巧思。 |
| **總分** | **100 分** | 滿分 100 分，提供 4 等級榮譽稱號與針對性教學診斷。 |

### 🏆 評價等級
- **90～100 分**：「傳說級變裝大師！」
- **70～89 分**：「超有創意的模仿高手！」
- **50～69 分**：「很棒的藝術挑戰者！」
- **0～49 分**：「再觀察一下，作品會更接近喔！」

## 🎮 四、 操作方式與無障礙支援

- **滑鼠拖曳**：按住道具卡片即可拖曳至角色身上或桌上的槽位，放開時自動吸附定位。
- **觸控拖曳**：支援 iPad、Android 平板與智慧型手機螢幕觸控拖曳。
- **點擊直覺操作（替代方案）**：在手機小螢幕上，可直接點擊道具卡片選取，再點擊目標槽位完成裝備；雙擊道具卡片更可一鍵自動佩戴！
- **點擊卸除**：點擊角色身上或桌上的已裝備道具，即可將其卸除放回道具欄。
- **姿勢與構圖控制**：點擊選項按鈕或拉動滑桿，人物即時平滑變換，不卡頓、不變形。

本遊戲嚴格遵守智慧財產權與公眾領域（Public Domain）使用規範，所使用之三幅世界名畫圖片均來自國際知名美術館提供之高解析度公眾領域藏品：

1. **《戴珍珠耳環的少女》（Girl with a Pearl Earring）**
   - 作者：約翰尼斯 ． 維梅爾（Johannes Vermeer, 1632–1675）
   - 館藏機構：荷蘭海牙毛里茨之家博物館（Mauritshuis, The Hague）
   - 授權狀態：公眾領域（Public Domain / CC0）
2. **《倒牛奶的女僕》（The Milkmaid / Het melkmeisje）**
   - 作者：約翰尼斯 ． 維梅爾（Johannes Vermeer, 1632–1675）
   - 館藏機構：荷蘭阿姆斯特丹國家博物館（Rijksmuseum, Amsterdam）
   - 授權狀態：公眾領域（Public Domain / Rijksstudio Open Data）
3. **《戴灰氈帽的自畫像》（Self-Portrait with Grey Felt Hat）**
   - 作者：文森 ． 梵谷（Vincent van Gogh, 1853–1890）
   - 館藏機構：荷蘭阿姆斯特丹國家博物館 / 梵谷博物館（Van Gogh Museum）
   - 授權狀態：公眾領域（Public Domain / CC0）

## 🚀 七、 GitHub Pages 靜態部署指南

本專案採純靜態（Vanilla HTML5 / CSS3 / JavaScript）架構，**不需要** 安裝 Node 相依套件，**不需要** 執行任何建置編譯指令（No npm build），可直接發布：

1. 將本專案推送至 GitHub Repository 的 `main` 分支。
2. 進入 GitHub 專案儲存庫頁面，點選頂部 **Settings** ➔ 側邊欄 **Pages**。
3. 在 **Build and deployment** 區塊：
   - **Source** 選擇 `Deploy from a branch`。
   - **Branch** 選擇 `main`，資料夾選擇 `/(root)`。
   - 點選 **Save** 儲存。
4. 稍候 1 至 2 分鐘，即可透過專屬網址開啟遊戲：
   `https://<你的 GitHub 帳號>.github.io/<儲存庫名稱>/`
