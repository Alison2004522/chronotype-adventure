# 《生日蛋糕小店長》（Birthday Cake Shop Manager）

一款結合**生活閱讀理解**、**實用數學運算**與**情境決策模擬**的 2D 互動式教育遊戲。  
適合國小五、六年級至國中一年級學生，在生動可愛的日系 Q 版蛋糕店情境中，學會從生活文本中擷取資訊、計算金額並做出正確的消費決策。

## 🎯 核心教育理念與學習目標

> **「生活中的閱讀不只是理解文字，更需要根據資訊做出正確判斷。」**

完成本遊戲後，學生將能培養以下素養能力：
1. **文本資訊擷取**：從蛋糕菜單中快速找出商品名稱、口味特色、尺寸及對應價格。
2. **生活情境決策**：根據聚會參加人數，挑選最適合分享的蛋糕尺寸（6 吋 4～6 人、8 吋 6～8 人、10 吋 8～10 人）。
3. **生活數學運算**：運用整數乘法（單價 × 數量）與加法計算外送運費，並進行預算比對。
4. **規則限制理解**：掌握「限定月份（7～8 月 / 12～2 月）」、「特殊運送（限門市取貨、10 吋 2 入超材無法配送）」與「提前預訂」等日常消費條款。
5. **養成細心習慣**：建立下單前審慎比對商品規格與配送條件的生活好習慣。

## 🚚 外送運費計算表與配送規則

- **門市自取**：運費一律為 **0 元**。
- **專人外送查詢表**：

| 尺寸規格 | 購買 1 個之運費 | 購買 2 個之運費 |
|:---:|:---:|:---:|
| **6 吋** | 150 元 | 180 元 |
| **8 吋** | 150 元 | 200 元 |
| **10 吋** | 200 元 | **超過配送體積，不提供外送** |

- **重要外送規定**：
  1. 外送服務時間僅限**下午 2 點（14:00）以後**。
  2. 每日下午 4 點前預訂為當日訂單，下午 4 點後訂購視為隔日訂單。
  3. HAPPY TIME 蛋糕體積與保鮮特性特殊，**僅限門市取貨**。
  4. 2 個 10 吋蛋糕因外送箱材積限制，系統會主動警示**無法外送**。

## 🎮 三大顧客訂單攻略

### 第一關：精打細算的生日派對
- **顧客**：小晴
- **需求**：聚會 5 人、預算 700 元、指定「水果與布丁」夾層、門市自取、買 1 個。
- **正解**：**城堡蛋糕，6 吋，1 個，門市自取**
- **計算**：單價 660 元 ＋ 運費 0 元 ＝ 總金額 660 元（未超出 700 元預算）。

### 第二關：夏日芒果派對
- **顧客**：小樂
- **需求**：朋友生日 7 月 20 日、聚會 8 人、最喜愛「芒果與椰子」、門市自取、買 1 個。
- **正解**：**浪漫嘉年華，8 吋，1 個，門市自取**
- **計算**：單價 990 元 ＋ 運費 0 元 ＝ 總金額 990 元（符合 7～8 月限定期，且 8 吋適合 6～8 人）。

### 第三關：外送訂單大挑戰
- **顧客**：小宇
- **需求**：替公司預訂 2 個 8 吋「巧克力蛋糕」，明日下午 3 點專人外送，總預算 2,000 元。
- **正解**：**邱比特蛋糕，8 吋，2 個，專人外送**
- **計算**：
  - 商品小計：880 元 × 2 ＝ 1,760 元
  - 外送運費：2 個 8 吋蛋糕運費 ＝ 200 元
  - 訂單總金額：1,760 元 ＋ 200 元 ＝ **1,960 元**（未超出 2,000 元預算）。

### 🏆 全通關營業總額
三筆訂單總和：**660 元 ＋ 990 元 ＋ 1,960 元 ＝ 3,610 元**  
*(註：畫面上明確標註此為三位不同顧客之銷售總額，非單一顧客消費)*

## 🛠️ 開發技術與安全部署規範

- **技術棧**：原生 HTML5、CSS3、原生 JavaScript（ES6+）、SVG 向量繪圖、Web Audio API。
- **相容性**：支援現代桌面瀏覽器（Chrome、Edge、Safari、Firefox）及 iOS / Android 平板與智慧型手機觸控。
- **資安與零洩漏**：純靜態單機運作，無後端伺服器、無任何 API 金鑰、無儲存個資風險。
- **繁體中文排版**：符合台灣教育部繁體中文用字規範、中英半形空格與全形標點符號標準。
